Jedna instalace, dva způsoby práce

Většina lidí začne jedním způsobem práce a postupně využívá oba. Službu i paměť mají společnou.

Týmy agentů pracují podle zadaného cíle. Spouští je časový plán, webhook nebo událost na GitHubu. Na schválení čekají jen u kroků, které určíte.

  • Agenti kontrolují každý pull request a opravují označené issues
  • Sledují doručenou poštu a navrhují události do kalendáře
  • Přes noc zpracují rešerši a zveřejní zprávu

S týmem komunikujete přes Telegram, e-mail nebo webové rozhraní.

Příklad: označené issue na GitHubu spustí úkol. Agenti pro rešerši, vývoj a kontrolu připraví opravu a vytvoří pull request. Každý pracovní den vznikne přehled pošty, agent si před odesláním e-mailu vyžádá schválení v telefonu a doručí shrnutí na Telegram.

Váš programovací agent získá trvalou paměť projektu, sdílené skills a tým, kterému předá review nebo rešerši. Mezitím může pokračovat v práci.

  • Připomeňte si, proč je kód navržen právě takto
  • Po každém commitu dostanete review
  • Z jednorázové opravy udělejte skill pro každou další session

Instalaci provede váš programovací agent

Návod na agents.vornik.io je napsaný pro agenty. Operace vyžadující vyšší oprávnění schvalujete vy.

  1. Vložte jeden prompt

    Do Claude Code, Codexu nebo svého agenta Hermes.

  2. Nainstaluje Vornik a ověří, že funguje

    Spustí službu i databázi, nastaví klíč k modelu a ověří dokončení prvního úkolu.

  3. Připojí se k Vorniku

    Váš agent získá vlastní projekt a paměť pro příště.
